# React Learn

Hands-on React learning platform with interactive lessons and live demos.

## Currently available

- **useReducer** — step-by-step tutorial with `userReducer`, comparative `useState` examples, and practical demos (form, auth, API fetch)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Build

```bash
npm run build
npm run preview
```

## Stack

- React 19 + Vite
- React Router
- react-syntax-highlighter (VS Code–style code blocks)
